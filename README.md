### 1. Clone Repository

```bash
git clone https://github.com/mudrickfarhan/auto-check-in-chainopera.git
```

### 2. Go To Bot Directory
```
cd auto-check-in-chainopera
```

### 3. Install
```
pip install requests 
```

### 4. Input your token (F12 - aplicattion - auth token)
```
nano token.txt
```

### 5. Run
```bash
python3 bot.py
```
